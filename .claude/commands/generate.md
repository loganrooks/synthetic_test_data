Generate sample synthetic test data files.

Use the synth_data_gen library to create sample EPUB, PDF, or Markdown files
for testing purposes.

Arguments ($ARGUMENTS):
- If empty, explain how to use the generate_data() function
- If a format is specified (epub, pdf, markdown), generate a sample file

Examples:
- `/generate epub` - Generate a sample EPUB file
- `/generate pdf` - Generate a sample PDF file
- `/generate` - Show usage instructions
